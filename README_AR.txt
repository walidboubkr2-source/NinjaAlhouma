نينجا الحومة — مشروع Android Beta

هذا مشروع Android Studio، وليس APK جاهزاً للتثبيت.

طريقة بناء APK من الهاتف باستخدام GitHub Actions:
1) فك ضغط الملف ZIP.
2) أنشئ مستودعاً جديداً في GitHub من المتصفح على الهاتف.
3) ارفع كل ملفات المشروع إلى المستودع، مع المجلد المخفي .github/workflows وملف build-apk.yml.
4) افتح تبويب Actions في المستودع ووافق على تفعيل Actions إذا طُلب.
5) افتح workflow باسم Build Ninja Alhouma APK واضغط Run workflow، أو ارفع الملفات إلى الفرع main ليبدأ البناء تلقائياً.
6) بعد انتهاء التشغيل بنجاح، افتح صفحة التشغيل (workflow run) وانزل إلى Artifacts.
7) نزّل NinjaAlhouma-Beta-APK.zip وفك ضغطه؛ داخله app-debug.apk.
8) افتح APK وثبّته. قد يطلب Android السماح للمتصفح/مدير الملفات بتثبيت تطبيقات غير معروفة؛ لا تسمح بذلك إلا للملف الذي بنيته بنفسك وتثق بمصدره.

ملاحظات:
- هذا مشروع Beta مبني على HTML داخل WebView.
- لا توجد حاجة للإنترنت داخل اللعبة بعد تثبيتها؛ الإنترنت مطلوب فقط للبناء عبر GitHub.
- إذا فشل البناء، افتح سجل Actions وانسخ آخر رسالة خطأ للمساعدة في إصلاحها.
